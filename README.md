# Грибной день рождения 🍄

Одностраничное приглашение на день рождения с тихой охотой (собираем грибы с гидом).
Стиль — нео-брутализм. Внизу по скроллу едет поезд 🚂, в углу — кнопка с грибным рэпом 🎵.
Доступ к странице — **только по токену** (StatiCrypt-шифрование).

## Структура

```
src/index.html     ← исходник страницы (открытый текст, правим здесь)
docs/index.html    ← зашифрованная версия (генерируется, её отдаёт GitHub Pages)
assets/            ← опционально: музыка/картинки, если не встраиваем в HTML
package.json       ← скрипт сборки (шифрование)
```

## ⚠️ Важно про приватность

- **Приватность репозитория НЕ делает сайт приватным.** На бесплатном/Pro аккаунте
  GitHub Pages публикует страницу **публично** — её видно всем, у кого есть ссылка.
- Поэтому защита сделана **шифрованием**: в `docs/index.html` без токена лежит только
  зашифрованный текст, прочитать/подсмотреть в «исходном коде» нельзя.
- **Токен не хранится в коде страницы.** Ты держишь его у себя и передаёшь гостям.
  Если хочешь записать его для себя — положи в `SECRET.md` (он уже в `.gitignore`,
  в открытый доступ не попадёт).

## Как задеплоить (пошагово)

> Финальные команды/флаги проверю и зафиксирую при первом реальном деплое —
> когда контент, фото и токен будут готовы.

### 1. Установить зависимости
```bash
npm install
```

### 2. Зашифровать страницу своим токеном
```bash
STATICRYPT_PASSWORD='ТВОЙ_ТОКЕН' npm run build
```
Возьмёт `src/index.html`, зашифрует и положит результат в `docs/index.html`
(плюс `docs/.nojekyll`, чтобы Pages не трогал файлы).

### 3. Запушить
```bash
git add docs && git commit -m "deploy" && git push
```

### 4. Включить GitHub Pages
`Settings → Pages → Build and deployment`:
- **Source:** Deploy from a branch
- **Branch:** нужная ветка, папка **/docs** → **Save**

Через минуту сайт будет тут: `https://<логин>.github.io/mushrooms/`

### 5. Раздать доступ
Гость открывает ссылку → вводит токен → видит приглашение.
**Ссылку и токен шли отдельно** (токен — в личку), не склеивай их в один URL.

## Как менять контент потом
1. Правишь `src/index.html`.
2. Повторяешь шаг 2 (перешифровать) и пушишь `docs/`.

Открытый `src/` GitHub Pages **не отдаёт** — его видно только тем, у кого есть
доступ к приватному репозиторию.

## Фото 🖼️
Чтобы фото тоже были **под токеном**, встраиваем их прямо в HTML как `base64`
(тогда они внутри зашифрованного файла). Скинь картинки — вставлю.
Альтернатива: положить в `assets/` как обычные файлы, но тогда они доступны по
прямой ссылке в обход токена.

## Музыка 🎵 («Тает лёд» / Грибы)
- Кнопка «врубить грибной рэп» в правом нижнем углу. Автозапуск со звуком браузеры
  запрещают, поэтому включается по нажатию.
- **Сам трек в репозиторий не добавлен** — из-за авторских прав. Варианты:
  - **A.** Свой файл `assets/music.mp3` (или встроенный `base64`, чтобы был под токеном).
  - **B.** Ютуб-эмбед официального клипа (звук — по клику).
- Скинь mp3 или ссылку — подключу.

## Поезд 🚂
Едет по низу экрана по мере прокрутки. Чистый CSS/JS, настраивать ничего не нужно.
Учитывает `prefers-reduced-motion` (для тех, кому анимации мешают).
