# Грибной день рождения Германа 🍄

Одностраничное приглашение в стиле нео-брутализм: собираем грибы и ягоды, баня-палатка,
озеро, пикник и туса. 1 августа. Сверху бегущая строка, внизу по скроллу едет поезд 🚂,
в углу — кнопка с треком «Тает лёд» 🎵. Доступ к странице — **только по токену**
(шифрование StatiCrypt).

## Структура

```
src/index.html        ← исходник (правим здесь). Tailwind вшит между TW:START/TW:END,
                        интерактивный JS — в inline-обработчиках (см. нюанс ниже)
src/tailwind.css      ← вход для Tailwind CLI
src/assets/music.mp3  ← трек (перекодирован в 128 kbps, ~2.3 МБ)
tailwind.config.js    ← тема: шрифты Unbounded/Golos, палитра, brut-тени
scripts/              ← inline-css.js, inline-audio.js, copy-assets.js
docs/                 ← ГЕНЕРИРУЕТСЯ: index.html (зашифрован) + assets/ + .nojekyll,
                        это и отдаёт GitHub Pages
```

## ⚠️ Важно про приватность
- **Приватность репозитория НЕ делает сайт приватным.** GitHub Pages публикует страницу
  публично — её видно всем, у кого есть ссылка.
- Поэтому защита сделана **шифрованием**: в `docs/index.html` без токена лежит только
  зашифрованный текст — ни имени, ни даты, ни ссылки не видно даже в «исходном коде».
- **Токен в коде страницы не хранится.** Ты держишь его у себя и передаёшь гостям.

## Сборка и деплой

### 1. Установить зависимости
```bash
npm install
```

### 2. Зашифровать своим токеном
```bash
STATICRYPT_PASSWORD='ТВОЙ_ТОКЕН' npm run build
```
`npm run build` (лёгкий режим, по умолчанию):
- собирает Tailwind и вшивает CSS в страницу (самодостаточно),
- шифрует `src/index.html` → `docs/index.html`,
- кладёт трек рядом: `docs/assets/music.mp3` (ленивая загрузка по клику),
- пишет `docs/.nojekyll`.

Приглашение выходит ~140 КБ — окно пароля появляется мгновенно; трек 2.3 МБ
подгружается только когда гость нажмёт кнопку. Минус: сам mp3 лежит отдельным файлом
и доступен по прямой ссылке (детали события при этом остаются зашифрованы).

**Вариант «музыка тоже под токеном»** (тяжелее):
```bash
STATICRYPT_PASSWORD='ТВОЙ_ТОКЕН' npm run build:embed
```
Трек встраивается в зашифрованную страницу (base64) — в открытом доступе ничего нет,
но `docs/index.html` весит ~6 МБ и грузится целиком до появления окна пароля.

### 3. Запушить
```bash
git add docs && git commit -m "deploy" && git push
```

### 4. Включить GitHub Pages
`Settings → Pages → Build and deployment`:
- **Source:** Deploy from a branch
- **Branch:** нужная ветка, папка **/docs** → **Save**

Через минуту: `https://<логин>.github.io/mushrooms/`

> ⚠️ Публикация Pages из **приватного** репозитория требует платного плана (Pro/Team/
> Enterprise). Если аккаунт бесплатный — см. раздел «Если план бесплатный» ниже.

### 5. Раздать доступ
Гость открывает ссылку → вводит токен → видит приглашение.
**Ссылку и токен шли отдельно** (токен — в личку), не склеивай в один URL.

### Вариант: ссылка с «зашитым» токеном (авто-вход)
Можно дать ссылку, которая открывается сразу, без ввода токена — он зашит хешем в части
после `#` (на сервер не уходит). Сгенерировать точную ссылку под свой адрес:
```bash
STATICRYPT_PASSWORD='ТВОЙ_ТОКЕН' npx staticrypt src/index.html -d /tmp/x --short --share 'https://<адрес-сайта>/'
```
- Формат: `https://<адрес-сайта>/#staticrypt_pwd=<хеш>`
- **Ссылка = ключ:** кто её получил — войдёт без токена. Удобно для чата отряда, но не постить публично.
- Работает, пока не меняются токен и `salt`. Файл `.staticrypt.json` (только `salt`, не секрет)
  закоммичен, чтобы пересборка в новой среде не поменяла соль и не сломала ссылку.
- Работает только по `https://`/`localhost` (не из файла с диска).

## Проверено ✅
Сквозной тест в headless-браузере подтвердил: верный токен расшифровывает страницу,
неверный — нет, до ввода контент не виден; после расшифровки играет музыка и едет поезд;
в зашифрованном `docs/index.html` нет ни имени, ни даты, ни токена, ни ссылки.

## Нюанс: JS и StatiCrypt
StatiCrypt вставляет расшифрованный HTML **без выполнения `<script>`**. Поэтому логика
поезда и музыки сделана на **inline-обработчиках** (`onload`/`onclick`) — они срабатывают
и во вставленном контенте. Добавляешь свой JS — вешай его тоже инлайном, не через `<script>`.

## Как менять контент потом
1. Правишь `src/index.html` (Tailwind-классы, тексты, ссылки).
2. Снова `npm run build` (или `build:embed`) и пушишь `docs/`.

Локальный предпросмотр: открой `src/index.html` в браузере или `npm run preview`.
Открытый `src/` GitHub Pages не отдаёт (Pages отдаёт только `docs/`).

## Осталось наполнить
- **Фото** в галерею (6 рамок «ФОТО 1…6»). Скинь — встрою (под токен через base64, либо в `assets/`).
- **Локация и карта** (секции «Где» и «Как добраться» сейчас с заглушками).

Имя, дата, программа дня и ссылка на Telegram-чат уже на месте — из твоего дизайна.

## Если план бесплатный (Pages из приватного репо недоступен)
Контент зашифрован, поэтому публичность хостинга сама по себе деталей не раскрывает. Варианты:
- отдельный **публичный** репозиторий только с содержимым `docs/` (без `src/`, чтобы открытый
  исходник не утёк) → Pages бесплатно;
- залить папку `docs/` на бесплатный статический хостинг (Netlify Drop, Cloudflare Pages, Vercel);
- оставить приватным и апгрейднуть план до Pro.
